# Dubbo : examen individuel des 71 écarts Snyk sans identité OSV Maven

Date : 2026-11-02. Le scan comparé utilise `cveOffline=true`, OSV actif et GCVE désactivé. Les verdicts portent sur ce scan et les sources primaires examinées ; le second scan en ligne active CVEProject, OSV et GCVE, avec NVD, EPSS, KEV, EUVD, CERT-FR et Retire désactivés. Il utilisait le code chargé avant la version de schéma v2 mais a reconstruit l’index depuis les CNA ; sa couverture GCVE était partielle. Une référence commune ne prouve pas un alias. Les plages CNA, l’état de l’index, les résultats du replay et les liens complets sont archivés dans [le fichier JSON](dubbo-snyk-primary-individual.json). Une plage de versions n’établit pas que les conditions d’exploitation sont réunies.

Sur les 71 occurrences, 38 ont une conclusion au niveau paquet/version et 33 restent sans conclusion définitive : 16 sources sans portée prouvée, 9 plages custom non décidables, 4 versions Netty non prouvées par la seule annonce, 2 conflits entre sources primaires et 2 autres cas indéterminés. Les conclusions ne démontrent pas que les conditions d’exploitation sont réunies dans le projet.
