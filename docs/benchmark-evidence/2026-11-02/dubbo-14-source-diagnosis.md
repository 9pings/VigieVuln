# Fourteen Dubbo findings absent from the expanded-source run

The CVEProject/OSV/GCVE run analysed here has SHA-256 `c32afcb4034e6dc33f05185a86c4c8ce8a3707552cd69cc996115aa63c5c7107`. The later schema-v2 reconstruction produced the identical set of 758 findings (SHA-256 `af878ed9b6d55c83d9189b18ecfb54e3ab1edc60279dcdd7af950d1505fcaae6`). Both warned of partial CVEProject coverage, unverifiable identities or versions, and partial GCVE coverage. It therefore does **not** prove complete default online behavior. The 14 rows are supported as affected package/version findings in [the individual evidence](dubbo-snyk-other-coordinates.json); the report contains no matching CVE for them.

The following diagnosis combines the actual Maven projection index in the test home with an independent execution of `extractMavenRelevantCve` and `affectedVerdict` on the current CNA metadata. Because the scan reported partial native coverage, these explain the observed projection/matcher barriers and are **not** proof that every exact CNA revision was loaded by the scan.

A safe general approach is to import an independently authorized, maintained multi-ecosystem source that declares exact package coordinates and interpretable version bounds, with explicit source provenance and withdrawal semantics. Where CNA metadata is insufficient, surface an unknown/coverage warning or seek correction upstream; do not promote a product-name or shared-reference heuristic to an affected verdict. A candidate source must be validated end-to-end before adding it to the server, proxy or seed. The GitHub global database is redistributable under CC BY 4.0 but currently supplies none of these 14 exact mappings; see [the separate source assessment](ghsa-global-source-assessment.md).

GitLab's publicly browsable legacy advisory database contains pages for ten of these coordinates, but its repository's [terms](https://gitlab.com/gitlab-org/security-products/gemnasium-db/-/blob/master/LICENSE.md) restrict downloading/copying and automated access. No GitLab corpus has been added or redistributed, and page existence is not a validated version verdict.
