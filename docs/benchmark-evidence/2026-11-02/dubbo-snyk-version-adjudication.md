## Evidence and unresolved limits

- **CVE-2023-6481: Already reported; vendor-confirmed equivalence.** The vendor explicitly states that both CVEs concern the identical underlying vulnerability. VV emits CVE-2023-6378 for logback-core 1.2.2. This is established incident equivalence, not an alias inferred from a shared reference. The CVE-specific range is narrower than Snyk, but no distinct missing incident is proven. Requires reachable logback receiver; this review does not assert deployment exposure. [CNA record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2023/6xxx/CVE-2023-6481.json); [logback-archive](https://logback.qos.ch/news-archive.html).

- **CVE-2019-9212: Indeterminate; disputed CVE.** The Maven Central 3.3.6 source archive still lacks both the QName entry and the XPath prefix added by the referenced patch. This contradicts treating 3.3.6 as proven fixed. However, the current CNA record is explicitly disputed and records the vendor position that blacklist customization is required. The technical blacklist gap is corroborated, but this review does not settle the disputed vulnerability classification. No deserialization payload was run; do not infer safety from the OSV fixed boundary or unconditional exploitability from the missing blacklist entries. [CNA record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2019/9xxx/CVE-2019-9212.json); [hessian-fix](https://api.github.com/repos/sofastack/sofa-hessian/commits/285b071d89c8dac21d32983e54f3a8788ca34c12); [sofa-hessian-issue-34](https://github.com/alipay/sofa-hessian/issues/34); [hessian-issue-comments](https://github.com/sofastack/sofa-hessian/issues/34/comments).

- **CVE-2026-83557: False alert for this version.** The owning-project advisory and CNA both start the relevant branch at 2.11.0. All five selected databind versions are older, and their complete Maven source archives contain no DefaultBaseTypeLimitingValidator. The named validator-gap advisory is therefore inapplicable to these exact versions. This does not assert that older polymorphic deserialization is otherwise safe. [CNA record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2026/83xxx/CVE-2026-83557.json); [GHSA-gx83-3vf8-gh7j](https://github.com/FasterXML/jackson-databind/security/advisories/GHSA-gx83-3vf8-gh7j); [jackson-databind-issue-6156](https://github.com/FasterXML/jackson-databind/issues/6156); [jackson-databind-introduction](https://raw.githubusercontent.com/FasterXML/jackson-databind/jackson-databind-2.11.0/src/main/java/com/fasterxml/jackson/databind/jsontype/DefaultBaseTypeLimitingValidator.java).
