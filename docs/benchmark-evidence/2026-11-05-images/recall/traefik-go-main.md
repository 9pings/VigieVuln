# Traefik main-module recall follow-up — 5 November 2026

This follows the original [comparison](../traefik-comparison.json) and [scoped review](../traefik-adjudication.md). The same OCI platform manifest, `sha256:903f89ddacc3059657565d3e5b3b8e8dcba4cc3b8af08183dad6fdc415459111`, was inventoried again; the old comparator outputs were not rerun or changed.

The binary at `/usr/local/bin/traefik` has SHA-256 `943bc67bf11a668636e1f5c505017e6bb024e01dfbce8e96b0500117b081afe5`. Its Go build information declares main module `github.com/traefik/traefik/v2` with version `(devel)`, clean Git revision `0c8778639a3cade0cf73aa26f56f822a4fb835e8` and VCS time `2024-02-12T15:14:04Z`. The digest-checked image configuration declares the source repository and version `v2.11.0`. The independently retrieved [Go module proxy version record](https://proxy.golang.org/github.com/traefik/traefik/v2/@v/v2.11.0.info) associates that module and tag with the same repository and revision. This is consistency of declared build and publisher metadata, not a reproducible-build or signature verification; symbol reachability remains unknown. The image tag by itself was not used as version evidence.

The fresh OSV Go-module query returned 100 matching raw advisory records, consolidated to 55 findings for this binary in the full report. The report has 267 raw findings versus 212 in the previous deduplicated replay, with all 207 original Trivy observations still matched under the original exact package/version/explicit-ID method. Under that same exact-coordinate method, 157 of 208 Grype observations match, unchanged: Grype represents the main program as a generic binary rather than a Go module.

A **separate** comparison relates Grype's generic Traefik binary to the identified Go main module only for this same immutable image and the same `/usr/local/bin/traefik` path and version. Under that evidenced relation, 38 of the 47 previously unmatched Grype program observations share an explicitly recorded CVE or advisory alias with a Go-module finding. Nine do not: CVE-2026-85595, CVE-2026-85594, CVE-2026-85597, CVE-2026-114639, CVE-2026-112778, CVE-2026-114642, CVE-2026-114635, CVE-2026-114656 and CVE-2026-114641. They remain unresolved; neither absence from OSV nor the other scanner's CPE match establishes a false positive or a confirmed affected-version verdict. Four additional Grype-only distro observations remain as described in the original review. [Machine comparison](traefik-comparison.json) preserves the individual matched and unmatched IDs and exact input hashes; [Go evidence](traefik-go-evidence.json) and [compressed OSV observations](traefik-go-osv-observations.json.gz) retain source data and declared identifiers.

The Go version record and main-module OSV query were fetched online into a copy of the earlier direct-source cache. A separate Alpine tracker refresh consulted 11 source packages and 257 CPE-derived candidates without request failures; its scope does not establish complete distro coverage. Enrichment of 47 explicit CVEs in the new main findings consulted NVD, KEV, EPSS, EUVD and CERT-FR; all 47 EUVD details were available. GCVE-0 identifiers were locally derived aliases, not independent GCVE advisory observations. The [tracker](traefik-alpine-online.json) and [enrichment](traefik-enrichment-online.json) records show the actual outcomes. Existing OSV distro snapshots and other historical data were reused: this is not a claim that every source was refreshed online.

An offline replay using the copied cache and all configured enrichment sources produced the same 267 package/advisory identity tuples and no warnings or attempted network connections. For the targeted Go-module query alone, the online and offline results contained the same 100 raw advisory IDs and aliases. This targeted parity is not a claim of full online/offline parity for all sources. The `go-main-identity` cache was separately verified through export/import before an offline image assessment.
