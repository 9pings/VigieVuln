# Debian current tracker candidates: NGINX replay

Run `node /tmp/vv-reduction-20261105/nginx/current-candidates/prepare.js` from the CLI checkout. The script uses the immutable commit metadata and the locally downloaded complete tracker list in `/tmp/vv-debian-current-commit.json` and `/tmp/vv-debian-CVE-current.list`, respectively. Their acquisition preceded this replay; the source list SHA-256, file modification time, commit, input paths, full results and per-tuple evidence are recorded in [`nginx-current-candidates-result.json`](nginx-current-candidates-result.json). It supplies existing online findings as `confirmedMatches`, writes the scoped candidate cache, and assesses it offline with a network tripwire. The file modification time is used as the source observation time; it is not a signed upstream publication timestamp. This is a replay of previously acquired source data, not a fresh network acquisition.

The historical snapshot ends 2026-08-31; the current commit is `34275c994acb81a18bc7d1230217f0ebe1061276`. Of the 185 Trivy package/CVE tuples absent from the historical snapshot after subtracting the nine ELA-supported tuples, all 185 are present as candidate observations: 94 have a current source-version threshold, 69 have such a threshold plus another release marked unaffected, and 22 have a current source note marking the package unfixed. These categories describe tracker evidence, not Debian 11 applicability. A different release's unaffected status neither confirms nor disproves Bullseye applicability; neither a threshold nor an unfixed note proves that a post-EOL Bullseye package is affected or identifies a Bullseye correction.

Overall, the cache contains 191 possible observations across the scanned inventory, six outside those 185 tuples. They cover 103 distinct CVE identifiers. Coverage is candidate-only, result indeterminate, scoped to 108 source packages; no source warnings were emitted. No original comparator outputs were changed and no candidates were added to confirmed findings. [`nginx-current-candidates-result.json`](nginx-current-candidates-result.json) includes the exact tuple-level comparisons and release annotations for independent review.
